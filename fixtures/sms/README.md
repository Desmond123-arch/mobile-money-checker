# SMS fixtures

Anonymised `MobileMoney` messages, one file per message shape (`payment_made.json` and so on), plus `failed.json`. Each entry holds the SMS (`sms`) and the parse result it must produce (`expected`). `src/domain/parse/__tests__/fixtures.test.ts` runs one test per entry.

## Provenance

Generated by `scripts/anonymise-sms.ts` from a private SMS Backup & Restore export, then formatted with Prettier. Regenerate with:

```
node --import ./scripts/lib/register.mjs scripts/anonymise-sms.ts /path/to/sms-export.xml
npx prettier --write fixtures
```

Entries marked `"synthetic": true` are copies of a real entry with a different amount, id and date, added where the real export has fewer than 5 messages of a shape.

## What is kept and what is changed

- Kept: amounts, fees, tax, times, layout and wording, the sender (`MobileMoney`).
- Fake words: every word outside the template vocabulary (names, merchants, free-text notes) becomes a made-up word. The same real word always maps to the same fake one, so a payment and its reversal still name the same counterparty. Words that are MoMo wording, public brands (MTN, Telecel, Paystack) or seed category keywords (`bread`, `trotro`) are kept.
- Ids: transaction ids are remapped to `9` plus ten digits; two messages that shared an id still share one. Merchant codes become `09NNNN`. The wallet number in transfer messages becomes `999NNNNNN`. The 12-digit value in "You have Paid" messages is rebuilt from the received time.
- Phone numbers: every phone number becomes `0 20000NNNN` or `233 20000NNNN` (national number `20000NNNN`). No other range appears. The fixtures test fails on any phone-like number outside it.
- Balances: every balance moves by one constant (GHS 7,771.23), so `before - (amount + fee + tax) = after` holds exactly as in the real data.

Raw exports are never committed (`*.xml` is git-ignored). The list of real words the script scrambled is written to `.local/sms-denylist.txt`, also git-ignored; the fixtures test uses it when present to prove none survived.
